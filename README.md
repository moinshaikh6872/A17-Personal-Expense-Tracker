# A17-Personal-Expense-Tracker
Weekly Assignment - Personal Expense Tracker
Weekly Assignment - Personal Expense Tracker

An HTML page to add an expense and view all expenses, with a FastAPI backend handling all four CRUD operations: add, view all, update one, delete one. Data is saved to `expenses.json` so it survives a server restart.

## Instructions
1. Install dependencies: `pip install -r requirements.txt`
2. Run the FastAPI backend: `uvicorn main:app --reload`
3. Open `index.html` in your web browser to manage your expenses.
